What happens next

  • You'll get an automatic email confirming we've received your request. If it doesn't arrive within a few minutes, check your spam folder. (If you sent the form with JavaScript turned off, we can't send this confirmation, but we still get your message.)
  • We reply from {% if support_email != "" %}{{ support_email }}{% else %}our support address{% endif %} to the email address you gave us. Add it to your contacts so our replies don't land in spam.

How we handle your message

The contact form is sent to a small program we run on Cloudflare (a Cloudflare Worker). It checks the form and emails it to our support inbox through Resend, an email delivery service, which also sends your confirmation email.

  • What's sent: your name, email address, store URL, theme version, topic, message and any attached files.
  • Where it's kept: in our support inbox.{% if support_email != "" %} Mail you send to {{ support_email }} is forwarded to the same inbox by Cloudflare Email Routing, which doesn't keep a copy.{% endif %} The Worker doesn't store your message or files. Resend keeps a copy of the emails it sends for up to 30 days (see Resend's privacy policy).
  • How long: we delete support emails and their attachments 12 months after your request is resolved, or sooner if you ask us to.
  • Spam protection: Cloudflare Turnstile checks that the form is sent by a person, and your IP address is used briefly to limit how many messages can be sent in a minute. We don't store it.
  • What we use it for: only to answer your request. We don't add you to a mailing list or share your details with anyone else.
  • Never send passwords, staff account access or customer data. If we need store access, we'll ask for a collaborator request through Shopify instead.

Open a support request on GitHub

You can also open a support request on GitHub (a free GitHub account is needed), or browse existing requests to see if your question has already been answered. GitHub requests are public, so leave out anything private.

What support covers

  • Covered: installing and setting up Plinth, using its settings and sections, and fixing problems with the theme's own features.
  • Not covered: custom code changes, third-party apps, and Shopify settings that aren't part of the theme. We'll still help you work out whether a problem comes from the theme. For store and account questions, contact Shopify Help Center.
