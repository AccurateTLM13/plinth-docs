Before you get in touch

  • Check the FAQ and troubleshooting page. Most setup questions are answered there.
  • Make sure you're on the latest version of Plinth ({{ site.theme_version }}). Your version is shown in Online Store > Themes.
  • If something looks broken, try it on an unedited copy of the theme with apps turned off. That helps us tell a theme issue from an app or code conflict.

Open a support request on GitHub

You can also open a support request on GitHub (a free GitHub account is needed), or browse existing requests to see if your question has already been answered. GitHub requests are public, so leave out anything private.

What support covers

  • Covered: installing and setting up Plinth, using its settings and sections, and fixing problems with the theme's own features.
  • Not covered: custom code changes, third-party apps, and Shopify settings that aren't part of the theme. We'll still help you work out whether a problem comes from the theme. For store and account questions, contact Shopify Help Center.
